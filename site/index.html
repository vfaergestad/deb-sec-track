Triage signals

Every signal on this page is a lookup in a published dataset, keyed by CVE id. Nothing is inferred, estimated by a model, or hand-scored.

How each signal is derived
KEV
The CVE appears in CISA's Known Exploited Vulnerabilities catalogue, meaning CISA has evidence of exploitation in the wild. Straight membership test on cveID.
ransomware
The same KEV record has knownRansomwareCampaignUse: "Known".
EPSS
FIRST's EPSS score: the modelled probability that the CVE is exploited in the next 30 days, published daily as a CSV. Shown with its percentile among all scored CVEs.
CVSS
CVSS v3.1 base score, computed with the standard formula from the vector the Linux kernel CNA published for that CVE. Only some CVEs carry a vector; the rest show as unrated rather than being given a made-up number.
AV:N
Attack vector from the same CVSS vector — Network, Adjacent, Local or Physical. For kernel bugs this splits the list more usefully than the score alone.
DSA/DLA
A Debian Security Advisory (stable) or LTS advisory shipped a fix for this CVE, taken from the security team's own advisory lists.
fix upstream
Debian lists the suite as vulnerable, and version arithmetic on the kernel CNA's fixed-version list shows a fix already released in the stable series that suite tracks. In other words the fix exists and has not been pulled in yet.
no fix yet
Debian lists the suite as vulnerable and upstream has published no fix for that stable series either.
