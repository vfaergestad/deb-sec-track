Where every signal comes from

Each one is a lookup in a published dataset, keyed by CVE id, or arithmetic over published values. Nothing is inferred or model-scored, so the same inputs always give the same answer.

KEV
Listed in CISA's Known Exploited Vulnerabilities catalogue — CISA has evidence of exploitation in the wild.
ransomware
That KEV record carries knownRansomwareCampaignUse: "Known".
EPSS
FIRST's EPSS: modelled probability of exploitation in the next 30 days, republished daily.
CVSS
CVSS v3.1 base score, computed with the standard formula from the vector the Linux kernel CNA published. CVEs without a vector show as unrated rather than getting an invented number.
AV:N
Attack vector from that same vector. For kernel bugs, network-reachable versus local-only splits the list more usefully than the score does.
vulnerable
The Debian Security Team lists your release as unfixed, and upstream has published no fix for the stable series it tracks either.
fix ready upstream
Debian still lists it as unfixed, but the stable series your release tracks already has a release containing the fix. Comparing version numbers tells you the fix exists and is waiting to be pulled in.
fixed
A fixed package version is available. Where a DSA or DLA shipped it, the advisory and its date are shown, which is the firm answer to "when was this fixed".
won't fix
Debian has triaged it and decided against an update for this release, with their stated reason.
not affected
This release never shipped the vulnerable code.

Data from the Debian Security Tracker, the Linux kernel CNA, CISA KEV and FIRST EPSS. Not affiliated with the Debian project.

Debian's own status is authoritative for whether a release is fixed. The upstream comparison is a convenience computed from version numbers, and a targeted backport can fix a CVE without changing the version Debian ships.
