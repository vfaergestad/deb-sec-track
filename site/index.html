How to read this

Every signal is a lookup in a published dataset keyed by CVE id, or arithmetic over published values. Nothing is inferred or model-scored, so the same inputs always give the same answer.

Per-release lifecycle states

vulnerable
The Debian Security Team lists this release as unfixed, and upstream has published no fix for the stable series it tracks either. There is nothing to install yet.
fix ready upstream
Debian still lists it unfixed, but the stable series this release tracks already has a version containing the fix, so it should arrive in a future kernel update.
fixed
A fixed package version is available. Where a DSA or DLA shipped it, the advisory and date are shown.
won't fix
Debian triaged it and decided against an update for this release, with their stated reason.
not affected
This release never shipped the vulnerable code.

Triage signals

KEV
Listed in CISA's Known Exploited Vulnerabilities catalogue, meaning there is evidence of exploitation in the wild. The strongest signal on this page.
ransomware
That KEV record carries knownRansomwareCampaignUse: "Known".
EPSS
FIRST's EPSS: modelled probability of exploitation in the next 30 days, republished daily.
CVSS
CVSS v3.1 base score, computed with the standard formula from the vector the Linux kernel CNA published. CVEs without a vector are shown as unrated rather than given an invented number.
AV:N
Attack vector. For kernel bugs, network-reachable versus local-only usually matters more than the score.
